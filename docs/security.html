Security Checklist — Bike Purchase Leads Management System (MVP)

Version: Draft for review  |  Date: 2026-10-17
This checklist identifies items to address — it is not a security audit. Single-user internal tool handling customer PII (names, phones, emails).

1. Data Sensitivity

#ItemHow addressed
S1PII identified and minimizedPII = customer name, phone, email. Stored only on the lead record; never copied into logs, URLs, or analytics.
S2Sensitive fields protected at restNeon Postgres encrypted at rest by default. No extra field-level encryption for MVP (internal single-user tool).

2. Authentication and Authorization

#ItemHow addressed
S3Auth checks on ALL protected routes, not just UI guardsMiddleware redirects unauthenticated page visits; every Server Action and Route Handler calls requireSession() first.
S4Authorization checked server-sideSingle-user: the only check is a valid session. No client-supplied roles or IDs trusted.
S5Session handlingSigned JWT in httpOnly + Secure + SameSite cookie; secret from env; reasonable expiry; logout clears the cookie.
S6Credential verificationbcrypt hash comparison (never plaintext); generic "invalid credentials" message; timing-safe compare.

3. Input Validation and Output Encoding

#ItemHow addressed
S7All inputs validated with Zod before business logicLogin form, CSV rows, lead create/edit, notes, search/filter/pagination params, upload metadata.
S8Output encoding / XSSReact escaping by default; no dangerouslySetInnerHTML; CSV-sourced strings treated as untrusted text.
S9File upload validationServer checks MIME type, extension, and size cap before forwarding to Frappe; rejects executables.

4. Secrets and Injection

#ItemHow addressed
S10No secrets in source code or chatDB URL, Frappe token, session secret, credentials all from env vars. Frappe token never leaves the server.
S11Secrets excluded from version control.env* in .gitignore (verify); Vercel env vars set via dashboard; sample values only in .env.example.
S12Parameterized queries onlyDrizzle ORM parameterizes all queries; no raw SQL with string interpolation.
S13CSV formula injectionLead fields are displayed in the app, not re-exported to spreadsheets in MVP; revisit if CSV export is added.

5. Transport and Storage

#ItemHow addressed
S14HTTPS enforced in all non-local environmentsVercel provides HTTPS by default; Secure cookies set.
S15Data not retained beyond necessityDelete removes lead + notes + events. No backups-retention policy needed for MVP beyond Neon's defaults.

6. Rate Limiting and Error Messages

#ItemHow addressed
S16Rate limiting on loginOPEN (architecture O3): DB-backed attempt throttling proposed; confirm approach in Phase 3 Milestone 1.
S17Error messages do not leak internalsGeneric user-facing messages; detailed errors server-logged only; no stack traces to the client.
S18Logs free of secrets and unnecessary PIILog action + lead id + timestamp only; review log lines before deploy.
